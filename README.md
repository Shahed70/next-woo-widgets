# Next Woo Widgets (Next Extra)

A high-performance Elementor & WooCommerce companion plugin providing premium-grade widgets across General, Archive, and My Account sections.

## Overview
- **Version:** 1.0.0
- **Author:** NextDevs
- **Requires at least:** WordPress 5.6, WooCommerce 5.0, Elementor 3.0
- **Tested up to:** PHP 8.2

## Features & Widgets

### 1. General
- **Advanced Coupon:** Interactive voucher cards with one-click copy, AJAX cart auto-apply, regional restriction notices, and urgency countdown timers.
- **Product Carousel:** Swiper-powered product slider with responsive column breakpoints, loop, autoplay speed, and rating/price visibility controls.
- **Flash Sale Products:** Urgency-driven sale catalog with live countdown clock and visual stock claim percentage bar.
- **Best Selling Product:** Auto-sorted by sales count with `#Rank` badges, social proof statistics, and Grid/List view options.

### 2. Archive
- **Product Filters:** Faceted filter panel featuring price range inputs, category check-lists with count tags, star ratings, stock availability, and a reset button.

### 3. My Account
Complete suite of 12 native WooCommerce account widgets:
- Account Dashboard
- Account Address
- Account Details
- Account Downloads
- Account Form - Login
- Account Form - Register
- Account Logout
- Account Navigation
- Account Order - Details
- Account Orders
- Account Wishlist
- Account Payment Methods

## Installation
1. Upload the plugin folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Manage active widgets via **WP Admin > Next Extra**.
